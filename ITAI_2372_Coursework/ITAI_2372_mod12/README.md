# Module 12 – Advanced AI & AGI Applications

## Overview
This module focuses on advanced artificial intelligence concepts, including Artificial General Intelligence (AGI) and real-world AI applications in high-risk environments. It explores how AI systems can move beyond task-specific functions to more adaptive, system-wide decision-making.

## A12 – AGI in Manufacturing Case Study

### Overview
This assignment explores how AGI could be applied in the manufacturing industry to improve efficiency, decision-making, and overall system performance.

### Key Focus Areas
- Differences between traditional AI and AGI
- Predictive maintenance improvements
- Real-time energy optimization
- Supply chain adaptability
- Human-AI collaboration

### Benefits
- Increased efficiency and reduced downtime
- Improved system-wide decision-making
- Better resource and energy management

### Challenges
- Job displacement concerns
- Data security and privacy issues
- Over-reliance on AI systems
- Ethical and accountability concerns

## NASA Space Mission AI Project

### Overview
This project proposes an AI-based predictive maintenance system for space missions. The system is designed to analyze sensor data and detect potential failures before they occur, improving mission safety and reliability.

### Deliverables
- Project_Proposal_CourtneyBernard_ITAI2372.docx (Written report)
- NASA_AI_Project_Presentation.pptx / PDF (Presentation slides)

### System Design
- Data collection from spacecraft sensors (temperature, pressure, vibration)
- Data processing and model training
- Real-time monitoring and anomaly detection
- Alert system for astronauts and mission control

### Benefits
- Improved astronaut safety
- Reduced mission failure risk
- Faster and more informed decision-making
- Increased operational efficiency

### Challenges
- Data quality and reliability
- False positives in anomaly detection
- High computational requirements
- Need for human oversight
