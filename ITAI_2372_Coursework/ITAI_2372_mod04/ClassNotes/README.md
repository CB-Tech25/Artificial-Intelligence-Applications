# Module 04 Class Notes – AI Applications

## Overview
These notes summarize key concepts from Module 04, focusing on how artificial intelligence is applied in real-world scenarios such as finance, data analysis, and automation.

## Objective
The goal of these notes is to capture and organize important ideas from lectures, making it easier to review and understand how AI techniques are used in different industries.

## Key Topics Covered

### AI in Financial Analysis
- AI can analyze large volumes of financial data quickly
- Helps identify trends and patterns in stock behavior
- Supports decision-making through predictive insights

### Sentiment Analysis
- Uses Natural Language Processing (NLP)
- Classifies text as positive, negative, or neutral
- Commonly applied to news, social media, and reviews

### Data Collection and Processing
- Web scraping and APIs (e.g., Yahoo Finance)
- Cleaning and preparing data for analysis
- Extracting meaningful information from raw data

### AI Applications
- Automation of repetitive tasks
- Decision support systems
- Real-time monitoring and alerts

## Importance
These concepts demonstrate how AI can:
- Reduce manual workload
- Improve efficiency
- Provide faster insights
- Support real-world decision-making

## Reflection
These notes helped reinforce how AI is used beyond theory and into practical applications. Understanding sentiment analysis and data processing shows how AI can turn raw data into meaningful insights.
