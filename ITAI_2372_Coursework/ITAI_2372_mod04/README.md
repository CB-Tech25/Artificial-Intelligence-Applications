# Module A04 – AI Applications and Analysis

## Overview
This module explores different real-world applications of artificial intelligence, including financial analysis, industry use cases, and ethical considerations. Each assignment focuses on a different use case to show how AI can be applied in practical scenarios.

## Assignments Included
- In-Class Assignment: AI-Based Stock News Sentiment Tracker
- Module 04 Class Notes
- AI in Fraud Detection Case Study

## Objective
The goal of this module is to understand how AI can be used to analyze data, automate decision-making, and solve real-world problems across different industries.

## Structure
Each assignment is organized into its own folder and includes:
- A README file explaining the assignment
- The original assignment submission file
